# Дзен Ремонт — официальный сайт

Официальный многостраничный сайт компании «Дзен Ремонт» из Санкт-Петербурга. Основное направление — ремонт коммерческих помещений; жилые объекты остаются отдельными направлениями. Репозиторий технически изолирован от Rica Workspace и не содержит его исходный код, историю или приватные данные.

## Что реализовано

- главная с прозрачными ценовыми ориентирами и доказательствами процесса;
- отдельные SEO-страницы под новостройку, старый фонд, коммерцию и косметический ремонт;
- страницы «ремонт по дизайн-проекту», «завершить после подрядчика» и кейс ЖК Neva Haus;
- интерактивный предварительный расчёт без обязательной передачи телефона;
- согласие на аналитику, UTM-атрибуция и события для GTM/Яндекс.Метрики;
- server-rendered контент, metadata, canonical, sitemap, robots и JSON-LD;
- `noindex` для локальных и предпросмотровых окружений; на официальном production-домене индексация включается через `NEXT_PUBLIC_INDEX_SITE=true`.
- редполитика Сарычевой для продающих и интерфейсных текстов в `.agents/redpolitika.md`.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
npm run lint
```

## Переменные окружения

Скопируйте `.env.example` в локальный `.env` и задайте официальный домен и рабочие идентификаторы аналитики. Для разрешения индексации требуется явно установить `NEXT_PUBLIC_INDEX_SITE=true`.

Миграционный аудит, рекомендации по запуску и список данных, которые нужно добавить, находятся в [docs/research-and-recommendations.md](docs/research-and-recommendations.md).
