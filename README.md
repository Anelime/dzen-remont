# НЕВА-ремонт — независимый редизайн сайта

Современный многостраничный сайт строительной компании из Санкт-Петербурга. Проект собран отдельно от Rica Workspace и не содержит его исходный код, историю или приватные данные.

## Что реализовано

- главная с прозрачными ценовыми ориентирами и доказательствами процесса;
- отдельные SEO-страницы под новостройку, старый фонд, коммерцию и косметический ремонт;
- страницы «ремонт по дизайн-проекту», «завершить после подрядчика» и кейс ЖК Neva Haus;
- интерактивный предварительный расчёт без обязательной передачи телефона;
- согласие на аналитику, UTM-атрибуция и события для GTM/Яндекс.Метрики;
- server-rendered контент, metadata, canonical, sitemap, robots и JSON-LD;
- `noindex` по умолчанию до подтверждения владельцем фактов и официального домена.
- редполитика Сарычевой для продающих и интерфейсных текстов в `.agents/redpolitika.md`.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
npm run lint
```

## Переменные окружения

Скопируйте `.env.example` в локальный `.env` и задайте официальный домен и подтверждённые идентификаторы аналитики. Для разрешения индексации требуется явно установить `NEXT_PUBLIC_INDEX_SITE=true`.

Подробный аудит исходного сайта, ограничения фактуры и список данных от владельца находятся в [docs/research-and-recommendations.md](docs/research-and-recommendations.md).
